# Employee Profile Generator

A Python-based employee profile generator that displays employee information in a structured format.

## Features
- Employee full name
- Age and work experience
- Job position and salary
- Employee identification code
- Department extraction
- Year code and initials extraction

## Technologies Used
- Python 3.14

## How to Run

1. Download this repository.
2. Open the folder in VS Code.
3. Run the following command:

```bash
py employee_profile.py
```

## Sample Output

```text
John Doe is 28 years old
Experience: 5 years
Employee: John Doe | Age: 28 | Position: Data Analyst | Salary: $75000
DEV
2026
JD
```
